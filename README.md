# ShelfSignal

Grocery demand forecasting demo. Runs fully in the browser.

Looks at past sales for 24 stores and suggests what to restock. Models: ARIMA, SARIMA, LSTM. Data is mock.

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS

No backend. No API keys.

## Run

Needs Node 18+.

```
npm install
npm start
```

Open http://127.0.0.1:5210


Pick a role on the first screen. Pages: Today, Forecast, Models, Stock, Buy, Sales, Network, Catalog.
